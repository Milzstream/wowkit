## Glowing Bars 2.5.0

### New

- New looks for the glow: in the table (/gb), the Animation column now offers each movement in two looks. Ants is Blizzard's glow, as before; clean is a clean line running around the button, or a soft frame when the glow stands still. Your current choice stays as it was.
- A What's new window lists the changes of every version. Open it with /gb changelog or from the top of the Settings page. After an update with new features, it opens once by itself; you can turn that off.
- The login message in the chat can be turned off: untick Show the login message on the Settings page.
