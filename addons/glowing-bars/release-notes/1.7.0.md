## Glowing Bars 1.7.0

### New

- **Party and raid buffs each have their own switch** on the Settings page. Off, only your own buffs are watched.
- **You choose when the group version glows**: from 1 to 5 members missing, set apart for a party (2 by default) and a
  raid (1 by default). You count too, but the group version never comes for you alone. For a paladin's Greater Blessing
  it counts the members of one class. This replaces the switch for a Greater Blessing on a single member; if you had it
  on, your party setting starts at 1.
- **A cooldown can glow for 1 second** once it is back, next to 2, 3, 5, 10 seconds or until pressed.
- **The API for UI addons can make a button round**: a registered button can ask for the round glow.
