## Glowing Bars 2.4.0

### Changed

- The addon uses far less memory: it stays at a few MB instead of climbing to 20-25 MB before the game clears it.
- Out of combat it checks once a second; in combat still twice a second, so procs and cooldowns are as quick as before.
- In the table (/gb), spells you haven't learned yet have a faded name and icon. You can still set their look.
